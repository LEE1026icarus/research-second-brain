# 선행연구 비교표

> Obsidian 커뮤니티 플러그인 **Dataview**가 필요합니다. 표는 논문 페이지 frontmatter(`theories`, `methods`, `design`, `sample_size` …)로 자동 생성됩니다.
> 이 파일은 `sb init`이 만든 템플릿입니다. 자유롭게 고쳐 쓰세요.

## 전체 논문

```dataview
TABLE WITHOUT ID
  file.link AS "논문",
  join(authors, ", ") AS "저자",
  year AS "연도",
  join(theories, ", ") AS "이론",
  join(methods, ", ") AS "방법",
  design AS "설계",
  sample_size AS "N",
  join(country, ", ") AS "국가"
FROM "wiki/papers"
SORT year DESC
```

## 조건 검색 예시 — 방법 + 설계
아래 두 값을 바꿔 쓰면 됩니다. 예: "BERTopic을 쓰고 종단 데이터를 쓴 논문"

```dataview
TABLE WITHOUT ID file.link AS "논문", year AS "연도", join(methods, ", ") AS "방법", design AS "설계", data_source AS "데이터"
FROM "wiki/papers"
WHERE any(methods, (m) => contains(lower(m), "topic")) AND (design = "longitudinal" OR design = "panel")
SORT year DESC
```

## 조건 검색 예시 — 이론 + 분야

```dataview
TABLE WITHOUT ID file.link AS "논문", year AS "연도", join(theories, ", ") AS "이론", join(domain, ", ") AS "분야"
FROM "wiki/papers"
WHERE any(theories, (t) => contains(lower(t), "disconfirmation"))
SORT year DESC
```

## 한계와 데이터 규모

```dataview
TABLE WITHOUT ID file.link AS "논문", sample_size AS "N", unit_of_analysis AS "분석단위", period AS "기간"
FROM "wiki/papers"
WHERE sample_size
SORT sample_size ASC
```
