# 검토 대기

> Dataview 플러그인이 필요합니다. 에이전트가 `review: pending`으로 표시한 페이지입니다. 확인한 뒤 `review: done`으로 바꾸세요.
> Zotero 하이라이트가 바뀌어 다시 반영할 논문은 터미널에서 `sb pending`으로 확인합니다.

## 확인이 필요한 페이지

```dataview
TABLE WITHOUT ID file.link AS "페이지", type AS "유형", review_reason AS "이유", file.mtime AS "수정"
FROM "wiki" OR "ideas"
WHERE review = "pending"
SORT file.mtime DESC
```

## 최근 수정된 페이지

```dataview
TABLE WITHOUT ID file.link AS "페이지", type AS "유형", file.mtime AS "수정"
FROM "wiki"
SORT file.mtime DESC
LIMIT 20
```
