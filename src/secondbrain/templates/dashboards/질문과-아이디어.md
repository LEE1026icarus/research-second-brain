# 질문과 아이디어

> Dataview 플러그인이 필요합니다. 아이디어는 확정 지식이 아닙니다.

## 열린 질문

```dataview
TABLE WITHOUT ID file.link AS "질문", status AS "상태", length(sources) AS "근거 자료 수"
FROM "wiki/questions"
WHERE status != "answered"
SORT file.mtime DESC
```

## 아이디어

```dataview
TABLE WITHOUT ID file.link AS "아이디어", status AS "상태", kind AS "종류", detected_by AS "발견 경로", confidence AS "확신도", related_project AS "프로젝트"
FROM "ideas"
WHERE status != "rejected"
SORT file.mtime DESC
```

## 기각된 아이디어

```dataview
LIST
FROM "ideas/rejected"
SORT file.mtime DESC
```
