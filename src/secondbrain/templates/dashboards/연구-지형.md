# 연구 지형

> Dataview 플러그인이 필요합니다. 내 라이브러리에서 어떤 이론·방법·설계가 많이 쓰였는지 셉니다. 적게 쓰인 조합은 연구 공백 후보입니다.

## 이론별

```dataview
TABLE WITHOUT ID key AS "이론", length(rows) AS "논문 수", rows.file.link AS "논문"
FROM "wiki/papers"
FLATTEN theories AS t
GROUP BY t
SORT length(rows) DESC
```

## 방법별

```dataview
TABLE WITHOUT ID key AS "방법", length(rows) AS "논문 수", rows.file.link AS "논문"
FROM "wiki/papers"
FLATTEN methods AS m
GROUP BY m
SORT length(rows) DESC
```

## 연구설계별

```dataview
TABLE WITHOUT ID key AS "설계", length(rows) AS "논문 수"
FROM "wiki/papers"
GROUP BY design
SORT length(rows) DESC
```
